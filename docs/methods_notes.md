# Methods notes: paper methods → code

This file maps each method in the paper to the code that implements it. Each section is filled in when the corresponding code is written.

| Paper method | Code | Notes |
|---|---|---|
| Re-run safety (not in the paper) | `bimanual/cache.py` | Skip a step if its outputs exist, write files atomically, keep append-only JSONL logs |
| Trial labels for Fig 1b-c: movement type and 8 direction wedges | `bimanual/conditions.py` (`trial_conditions`, `which_target`) | Faithful port of `tuningAnalysis.m:30-53, 154-202`. Keeps the MATLAB quirks: angles are floored to whole degrees, and a vector exactly on an axis gets NaN. `goCue` is 1-based in the `.mat` files. |
| MATLAB/Octave reference oracle | `matlab_reference/export_tuning_reference.m` | Runs `tuningAnalysis.m` lines 13–118 verbatim, without plotting, and saves the tuning curves for comparison with the Python port |
| Fig 5 TTA (500-ms simultaneous dwell, 10-s timeout) | `bimanual/behavior.py::time_to_acquisition` | ASSUMPTION: TTA is measured to the end of the dwell (`include_dwell=True`). The target radius is a parameter, to be read from the data. |
| Fig 5 angular error (300–500 ms after go) | `bimanual/behavior.py::angular_error` | ASSUMPTION: the target direction is fixed at the go cue; movement direction comes from the per-bin cursor displacement; bins with no movement are skipped. |
| Fig 4e speed traces | `bimanual/behavior.py::speed_profile` | Speed per bin |
| 95% bootstrap CIs (10k) | `bimanual/stats.py::bootstrap_ci` | Percentile bootstrap; NaNs (failed trials) are dropped |
| Eq. 1–2 encoding model, cvOLS | `bimanual/encoding.py::cv_ols` | `method="kfold"` (the paper's 5-fold: train on the other folds, test on fold k alone) or `"splithalf"` (50 random trial halves; MAIN, register #23). Splits are always by trial (`groups`). |
| Tuning strength (Fig 2b) | `encoding.py::cv_magnitude`, `tuning_strength` | Unbiased squared norm = mean of cross-fold products <train_k, test_k>; magnitude = signed square root; a hand's strength = mean of its x and y magnitudes. DEVIATION: reimplemented from the Willett et al. 2020 description, not their code. |
| Tuning correlation (Fig 2c) | `encoding.py::cv_correlation` | Channel-centered (Pearson). Models from different trials use full-fit cross products; within one model, cross-fold products. Can slightly exceed ±1. |
| Eq. 4 laterality axis and removal (Figs 2, 3) | `encoding.py::laterality_axis`, `remove_axis` | Removal projects out the unit b_lat; a refit then gives b_lat ≈ 0 |
| RNN targets (Fig 4b; Supp Fig 3) | `bimanual/targets.py::build_targets` | ASSUMPTION: "saturated" = min-jerk speed bell clipped at `sat`=0.5 of its peak and rescaled (alternative: `hold_to_end=True`). 200-ms reaction time. 4 context classes. Balancing strata: delay×3 + rest + movement type × quadrant. |
| Temporal fracturing (Fig 4c-d) | `bimanual/augment.py::SnippetSampler` | 10-s snippets (500 bins); ASSUMPTION: clips are 10–40 bins (200–800 ms); dilation U[0.5, 2] by linear interpolation (labels use the nearest bin); strata sampled uniformly; train/val split by trial before augmentation. ASSUMPTION: velocity amplitude is not rescaled by the dilation. |
| Non-augmented baseline (Fig 4d) | `augment.py::raw_snippets` | Consecutive 500-bin windows in the original order |
| Session catalogue and block labels | `bimanual/sessions.py` | Supp Table 2 plus the readme's block conditions, checked against the data by `scripts/01_inventory.py` |
| Loading and preprocessing (block-mean removal, ×50 Hz, z-score) | `bimanual/io.py` | Time-major arrays; the only place where 1-based `goCue` becomes 0-based |
| Trial windows; `computeFeatureMatrices` port | `bimanual/epochs.py` | Windows are inclusive, like MATLAB: (15, 35) = 21 bins |
| Fig 1b-c tuning curves (port of `tuningAnalysis.m`) | `bimanual/tuning.py::tuning_curves` | Matches Octave running the authors' code to 3e-14 (`pixi run compare-reference`) |
| Direction quadrants (Supp Fig 1 ANOVA, augmentation balancing) | `bimanual/conditions.py::quadrant`, `trial_quadrants` | ASSUMPTION: axis-aligned quadrants of the cursor→target vector at the go cue. Targets are at random positions; directions are evenly spread. |
| Fig 5 TTA source | `durationBinnedMove` (logged) | Decision from step 0.3: use the task's logged trial length (≥ 499 bins = timeout failure); `behavior.time_to_acquisition` is a sanity check only |
| Data version | Dryad download (current version) | ASSUMPTION: the 3 Dryad versions have identical data and differ only in the README (zip size is 138.35 MB in all) |
| Fig 1b-c tuning curves with CIs | `scripts/fig1_tuning.py` | Trial-mean rates over bins 15–35; 10k bootstrap over trials; centred like `tuningAnalysis.m`; asserts equality with the verified port |
| Supp Fig 1 single-electrode ANOVA and FVAF | `bimanual/stats.py::anova_fvaf`, `scripts/fig1_supp_anova.py` | 1-way ANOVA over 4 quadrants, tuned if p < 1e-5; FVAF = SS_dir / SS_total |
| Figure style | `bimanual/plotting.py` | Fixed palette slots: blue = unimanual, orange = bimanual; hatching = left hand |
| Fig 2 block sets | `bimanual/blocksets.py` | `adjacent_all` (main, n = 25), `all_pairs_mixed` (38), `adjacent_mixed` (17) |
| Encoding regressors | `conditions.trial_directions` | Unit direction at the go cue (register #21) |
| Fig 2b-c, Supp Table 1, Supp Fig 1d | `scripts/fig2_tuning_change.py` | Three cvOLS models per set (uniR, uniL, bi); suppression = bi/uni strength; 4 correlation types × x/y; pairwise two-sample t-tests |
| Fig 2 PCA (day 1881) | `scripts/fig2_pca.py` | OL trials; z-scored block-wise; trial means over bins 15–35; SVD; condition-centroid distances in the top 2/3 PCs and the full space |
| Fig 2 dPCA variance (laterality / direction / interaction / time) | `bimanual/dpca_analysis.py`, `scripts/fig2_dpca.py` | Own marginalization (each factor absorbs its interaction with time, as in Kobak et al. 2016); two-split CV variance = sum(M1·M2), averaged over 100 splits. The dPCA package is installed but not needed for the variance numbers. |
| Fig 3 / Supp Fig 2 single-bin decoders | `bimanual/decoders.py`, `scripts/fig3_decoding.py` | Stratified trial folds; ridge (alpha sweep by CV r); FFN 1×512 ReLU (register #25). Laterality removal is fitted on the training fold only. Jitter = idle speed / active speed. Paired bootstrap over trials for comparisons. |
| Fig 3 simulations, fSNR (Supp Fig 4) | `bimanual/simulate.py`, `scripts/fig3_simulations.py` | Eq. 4 population with RH-LH correlation ρ (exact) and a laterality scale; Eq. 3 i.i.d. noise with σ calibrated to the real single-bin fSNR; clip ≥ 0. fSNR = mean diag(D) / std(ε) from decoded = D·true + c + ε. |
| RNN decoder (Supp Fig 3) | `bimanual/rnn.py` | Day-affine (identity init) → GRU(512) → velocity + context heads; MSE + CE + L2; white-noise and per-snippet mean-drift augmentation; atomic checkpoints with RNG state, so resume is exact |
| Fig 4b-d RNN raw vs augmented | `scripts/fig4_rnn.py` | Block split (train 1–5 / val 6 / test 7); paired random search; continuous zero-state decode of whole blocks; r per dim; roughness = mean abs(Δv) / std(v) |
| Fig 5a-c, Fig 4e online re-scoring | `scripts/fig5_behavior.py` | CL blocks only. Success = durationBinnedMove < 499; TTA = logged × 20 ms (successful trials, and with failures = 10 s); angular error per moving hand at 300–500 ms; 10k bootstrap CIs. Sanity check: TTA recomputed at radius 60 agrees within 2 bins on 60% of day-1776 trials, so the logged value is used. |
| Ext. Phase 8 LSTM vs GRU | `bimanual/rnn.py` (`RNNDecoder(cell=)`), `scripts/ext_lstm.py`, `scripts/ext_lstm_plot.py` | LSTM forget bias 1 (#32); paired search, same 10 settings and seeds (#33); GRU 2–8-s search added (#34); LSTM-433 parameter-matched; Wilcoxon + bootstrap CI on paired val r |
| Ext. closed-loop proxy | `bimanual/proxy.py` | Day-1869 CL blocks; target = unit cursor→target vector of the active hand from go+10 bins to move end (minus the dwell), 0 otherwise; r, angle at 300–500 ms, sustain, idle-hand jitter (#35) |
| Ext. Phase 9 one array | `scripts/ext_arrays.py`, `scripts/ext_arrays_plot.py` | Channels 1–96 / 97–192 (#36, checked against the correlation structure); Phase 8 best hyperparameters (#37); zero-out = 0 in z-units (#38); random-96 control |
| Ext. Phase 10 job queue | `bimanual/jobs.py` | File-based queue: priorities, `requires` prerequisites, O_EXCL claim locks, one `trials_w{k}.jsonl` per worker; resumable. 1 worker chosen after the concurrency smoke test (2–3 workers gave lower total throughput and exhausted RAM) |
| Ext. Phase 10 feasibility runs | `scripts/ext_feasibility.py`, `scripts/ext_feasibility_plot.py`, `scripts/fig4_rnn.py` (`Data(channels, day, blocks)`), `bimanual/rnn.py` (`chan_dropout`) | Channel dropout (#39); data amount (#40); days 1750 / 1867 splits (#41); test-time muting zero / dead / noisy (#42); `timing.json` tracks measured vs planned GPU time |
| Ext. Phase 10 channel selection | `bimanual/select.py`, `scripts/ext_select.py` | Surrogate ridge on raw + exponentially smoothed features; greedy forward + best-swap refinement; group lasso by FISTA with ridge refit; 1,000-subset random baseline; LSTM ablation ranking; blocks 1–6 only (#43) |
| Ext. Phase 11 TX vs SBP | `bimanual/sbp.py`, `scripts/ext_sbp.py`, `scripts/ext_sbp_plot.py` | Rigotti-Thompson T5 h5 loader; leave-one-block-out ridge (inner-LOBO α) and FFN; paired random subsets for TX and SBP; muting modes as #42 with an SBP floor (#46); SBP residual and TX→SBP R² (#44–46) |
| Paper-style figures (figure comparison) | `scripts/paper_style_figures.py`, `scripts/make_figure_comparison.py` | Our results redrawn in the paper's panel layouts; median TTA with failures = 10 s; Fig 5a = 6 sessions incl. 1881/1883 simultaneous; angular error = net displacement 300–500 ms, median; jitter per x / y dimension |
| Diagnostics of paper-vs-ours differences | `scripts/diagnose_differences.py` | D1 Supp Fig 1 threshold / grouping / window; D2 angular-error definition; D3 FFN training variants; D4 cvOLS estimator × regressors (Eq. 2 per-step) |
